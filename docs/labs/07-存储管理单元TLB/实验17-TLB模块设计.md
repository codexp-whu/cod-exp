# 实验17：TLB模块设计

!!! info "原书参考"

    [《CPU设计实战：LoongArch版》9.1 TLB模块设计分析 / 9.2.1 实践任务17：TLB模块设计](https://bookdown.org/loongson/_book3/chapter-mmu-design.html)

## 实验目标

- 理解虚实地址转换：虚地址经 TLB 查出实页号与权限，拼成实地址。
- 实现一个独立可仿真的 TLB 模块：查找、写入、替换。
- 掌握**全相联**映射与 LRU/随机替换策略的实现。

## 知识背景

### TLB 是一张"地址翻译缓存"

页表存在内存里，逐次查表太慢。TLB 把最近的页表项搬到 CPU 内部：

```text
虚地址 = [虚页号 VPN | 页内偏移]
              ↓ TLB 查找（比较所有表项的 VPN 与 ASID）
命中 → 实页号 PPN + 权限位（V、D、PLV）
未命中 → 触发 TLB 重填例外（实验 19 的事，这里先返回未命中）
```

### LoongArch TLB 的表项结构

每个表项是"奇偶双页"：一个表项由 **E**（存在位）、**两个页表项 T0/T1** 组成，VPN 的最低位选择 T0 还是 T1——一次比较覆盖相邻两页。表项还有 **G** 位（全局，忽略 ASID 比较）、**ASID**（地址空间标识，进程隔离）。

### 关键设计点

- **全相联查找**：表项不多（LoongArch32R 为 16 项），用比较器阵列并行比对；
- **替换**：TLB 满时的牺牲者选择，课程要求实现 LRU（或随机）；
- **读写端口**：CPU 的查找端口（每拍取指/访存都要查）与软件维护端口（`tlbwr`/`tlbfill` 写入）并存，注意**同拍读写**的冲突处理。

## 任务要求

1. 实现独立 TLB 模块（含表项存储、查找、写入、替换）；
2. 编写完备的仿真测试：命中/未命中、ASID 匹配与不匹配、G 位、D 位权限、替换策略；
3. 统计一组典型访存序列的命中率。
