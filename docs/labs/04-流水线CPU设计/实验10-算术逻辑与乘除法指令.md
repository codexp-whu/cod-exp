# 实验10：算术逻辑运算指令和乘除法运算指令添加

!!! info "原书参考"

    [《CPU设计实战：LoongArch版》6.1.1 实践任务10：算术逻辑运算指令和乘除法运算指令添加](https://bookdown.org/loongson/_book3/chapter-add-more-user-instr.html)

## 实验目标

- 在流水线框架上扩展算术逻辑指令：`addi.w`/`add.w` 全家（含减法）、`and`/`or`/`nor`/`and`/`xor`/`or` 立即数变体、移位指令等（以课程给定清单为准）。
- 接入乘除法单元，处理**多周期执行部件**引入的流水线停顿。

## 知识背景

### 指令扩展的套路

到实验 9 为止，你已拥有"指令域提取 + 控制信号表"的译码结构（实验 6 建立）。扩展一条新指令 = 译码表加一行、ALU 操作集加一项、func 测试加覆盖。真正的难点不在加法，而在**乘除法**。

### 乘除法的特殊性

加减逻辑移位一拍完成，乘除法不行：

- 32 位乘法在 FPGA 上综合出的组合乘法器可能勉强一拍，但除法（恢复/不恢复余数、逐位迭代）通常要 **16~32 拍**；
- 乘除法单元做成**独立多周期部件**：EX 级遇到乘除指令，整机停顿，等它算完再放行流水线；
- 多周期部件的握手（busy/done 信号）、停顿期间流水级寄存器的冻结，是新的控制逻辑。

### LoongArch 乘除的细节

乘法有 `mul.w`/`mulh.w` 等（高低位分开的结果）；除法 `div.w`/`mod.w` 需注意**有符号除法向零取整**与**除零、溢出**的架构规定行为（结果值不由你发挥，查手册）。

## 任务要求

1. 扩展算术逻辑运算指令（以课程指令清单为准），全部通过 func 测试；
2. 实现多周期乘除法单元及与之配套的流水线停顿控制；
3. 处理乘除法期间的**其他相关**：乘除结果寄存器也是前递网络的新来源。

## 验收标准

- [ ] 扩展指令的 func 功能测试全部通过；
- [ ] 乘除法期间流水线行为正确（无指令丢失、无错误前递）；
- [ ] 提交源码与实验报告。
