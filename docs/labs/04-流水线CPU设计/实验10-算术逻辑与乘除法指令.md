# 实验10：算术逻辑运算指令和乘除法运算指令添加

!!! info "原书参考"

    [《CPU设计实战：LoongArch版》6.1.1 实践任务10：算术逻辑运算指令和乘除法运算指令添加](https://bookdown.org/loongson/_book3/chapter-add-more-user-instr.html#subsec-exp10)

## 实验目标

- 在已有的流水线CPU上添加算术逻辑运算类指令和乘除法运算类指令。

## 实验内容

本实践任务要求在实验九实现的CPU基础上完成以下工作：

添加算术逻辑运算类指令：**slti、sltui、andi、ori、xori、sll、srl、sra、pcaddu12i**。

添加乘除运算类指令：**mul.w、mulh.w、mulh.wu、div.w、mod.w、div.wu、mod.wu**。

!!! warning "乘除法是多周期操作"

    32 位的乘除法无法在流水线的一拍内完成，需要设计独立的多周期乘除法部件，并在其运算期间冻结流水线。注意与阻塞、前递逻辑的配合：乘除结果同样要接入前递网络。

!!! info "测试程序请选择EXP10"

## 实验步骤

1. 将所实现CPU的代码更新至`mycpu_env/myCPU/`目录中。
2. 修改func配置文件——`mycpu_env/func/include/test_config.h`，选择exp10的配置，编译。（`make EXP=10`）
3. 打开`gettrace` 工程——`mycpu_env/gettrace/gettrace.xpr`。运行`gettrace` 工程的仿真（进入仿真界面后，直接点击run all等待仿真运行完成），生成新的参考trace文件`golden_trace.txt`（`mycpu_env/gettrace/golden_trace.txt`）。要等仿真运行完成，`golden_trace.txt`才有完整的内容。
4. 进入 `mycpu_env/soc_verify/soc_bram/run_vivado/` 目录下启动验证myCPU的工程。如果该目录下尚未创建工程，请利用该目录下的 `create_project.tcl` 文件创建工程。如果该目录下已有前一实践任务创建过的工程，可以在打开工程后，更新项目中CPU实现文件的列表。
5. 对工程中的`inst_ram`重新定制。
6. 在验证myCPU的工程中运行仿真（进入仿真界面后，直接点击run all），进行功能验证与调试，直至仿真测试通过。
7. 在验证myCPU的工程中综合实现后生成bit流文件，进行上板验证。

## 验收标准

- [ ] 实验10 测试程序（n1~n36，共36个功能点）仿真PASS。
- [ ] 上板两个双色LED全为绿色，数码管显示"2400 0024"。

!!! tip "实现提示"

    - 各指令的编码与语义请对照[LoongArch32R指令集手册](https://www.loongson.cn/uploads/images/2023041918122813624.%E9%BE%99%E8%8A%AF%E6%9E%B6%E6%9E%8432%E4%BD%8D%E7%B2%BE%E7%AE%80%E7%89%88%E5%8F%82%E8%80%83%E6%89%8B%E5%86%8C_r1p03.pdf)逐一核对；
    - 有符号除法注意向零取整，除零、溢出（如 `0x80000000 / -1`）的行为按手册规定实现；
    - 乘除部件运算期间，流水线中的阻塞控制与实验八的逻辑可以复用。
