# 实验13：添加其它异常支持

!!! info "原书参考"

    [《CPU设计实战：LoongArch版》7.1.2 实践任务13：添加其它异常支持](https://bookdown.org/loongson/_book3/chapter-support-exception.html#subsec-exp13)

## 实验目标

- 为 CPU 添加更多异常和中断的支持，完善精确异常框架。

## 实验内容

本实践任务要求在实验十二实现的CPU基础上完成以下工作：

- 为CPU增加异常支持：**取指地址错乱（ADEF）、地址非对齐（ALE）、断点（BRK）、指令不存在（INE）**。
- 为CPU增加中断支持：包括 **2 个软件中断、8 个硬件中断和定时器中断**。
- 为CPU增加控制状态寄存器：**ECFG、BADV、TID、TCFG、TVAL、TICLR**。
- 为CPU增加读取计数器指令：**rdcntvl.w、rdcntvh.w、rdcntid**。

!!! warning "中断的引入时机"

    中断是异步事件，但响应必须选择**指令间隙**：不打断已进入流水线的指令。常用做法是在取指时伴随指令打上"携带中断"标志，该指令提交时若中断仍有效则按异常响应，其后指令被冲刷。中断的使能与屏蔽由 CRMD.IE、ECFG.LIE 与 ESTAT.IS 共同决定。

!!! info "测试程序请选择EXP13"

## 实验步骤

1. 将所实现CPU的代码更新至`mycpu_env/myCPU/`目录中。
2. 修改func配置文件——`mycpu_env/func/include/test_config.h`，选择exp13的配置，编译。（`make EXP=13`）
3. 打开`gettrace` 工程——`mycpu_env/gettrace/gettrace.xpr`。运行`gettrace` 工程的仿真（进入仿真界面后，直接点击run all等待仿真运行完成），生成新的参考trace文件`golden_trace.txt`（`mycpu_env/gettrace/golden_trace.txt`）。要等仿真运行完成，`golden_trace.txt`才有完整的内容。
4. 进入 `mycpu_env/soc_verify/soc_bram/run_vivado/` 目录下启动验证myCPU的工程。如果该目录下尚未创建工程，请利用该目录下的 `create_project.tcl` 文件创建工程。如果该目录下已有前一实践任务创建过的工程，可以在打开工程后，更新项目中CPU实现文件的列表。
5. 对工程中的`inst_ram`重新定制。
6. 在验证myCPU的工程中运行仿真（进入仿真界面后，直接点击run all），进行功能验证与调试，直至仿真测试通过。
7. 在验证myCPU的工程中综合实现后生成bit流文件，进行上板验证。

## 验收标准

- [ ] 实验13 测试程序（n1~n58，共58个功能点）仿真PASS。
- [ ] 上板两个双色LED全为绿色，数码管显示"3A00 003A"。

!!! tip "实现提示"

    - 各异常的检测位置不同：ADEF 在取指时、INE/BRK 在译码时、ALE 在访存时（ALE 还要把出错地址记入 BADV）。异常标志需随流水级传递，在提交点按指令序仲裁；
    - 定时器：TCFG 配置定时器并选择周期，TVAL 反映当前计数值，TICLR 用于清定时器中断。
