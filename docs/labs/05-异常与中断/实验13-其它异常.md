# 实验13：添加其它异常支持

!!! info "原书参考"

    [《CPU设计实战：LoongArch版》7.1.2 实践任务13：添加其它异常支持](https://bookdown.org/loongson/_book3/chapter-support-exception.html)

## 实验目标

- 把异常检测通用化：**地址错乱、取指/访存缺页（为 MMU 预留）、整数溢出、保留指令、断点**等（以课程清单为准）。
- 实现**中断**响应：外部异步事件的精确引入时机。

## 知识背景

### 异常检测的通用化

实验 12 只有一条 `syscall`。通用化后，各级都要布下哨点：

| 异常类型 | 检测位置 | 要点 |
| -------- | -------- | ---- |
| 取指地址错乱 / 缺页 | IF | 目标地址不对齐（非 4 字节）等 |
| 保留指令 | ID | 译码不认识的 opcode |
| 整数溢出 | EX | `add.w`/`sub.w` 溢出（`Ecode=0x0C`） |
| 访存地址错乱 / 缺页 | MEM | `ld.h` 地址非半字对齐等 |

各哨点的异常标志沿流水线传递，在提交点按**指令序**仲裁出该响应的那一个。

### 中断与异常的区别

异常是**同步**的：同一条程序反复跑，异常总在同一条指令上。中断是**异步**的：随时可能到来。LoongArch 的响应规则是"**指令间隙**"引入——中断不打断已进入流水线的指令，等当前指令提交后、下一条尚未生效前切入。

实现上：中断请求在取指时伴随指令一起带上"携带中断标志"进入流水线；若执行到它时中断仍在且未被屏蔽，就在该指令位置触发异常语义，之后的指令被冲刷。

中断号、屏蔽与使能（CRMD.IE、ECFG.LIE 与 ESTAT.IS）共同决定"是否响应、响应哪个"。

## 任务要求

1. 实现课程要求的全部异常类型的检测、编码与响应；
2. 实现中断的请求采样、使能屏蔽逻辑与指令间隙响应；
3. 通过含异常触发场景的功能测试（如故意执行保留指令、非对齐访存）；
4. 中断响应测试：外部请求到来时，精确在指令边界切入。

## 验收标准

- [ ] 各类异常的触发与返回行为符合 LoongArch 规范；
- [ ] 中断在指令间隙精确响应，现场（ERA、PRMD）记录正确；
- [ ] 提交源码与实验报告。
