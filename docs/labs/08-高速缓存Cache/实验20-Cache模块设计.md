# 实验20：Cache模块设计

!!! info "原书参考"

    [《CPU设计实战：LoongArch版》10.1 Cache模块的设计 / 10.2.1 实践任务20：Cache模块设计](https://bookdown.org/loongson/_book3/chapter-cache-design.html)

## 实验目标

- 理解 Cache 的组织：**组相联**、Tag/Index/Offset 划分、LRU 替换、写策略。
- 实现独立的 Cache 模块：CPU 侧类 SRAM 接口、总线侧 AXI 接口、未命中处理状态机。
- 处理 Cache 的**硬件初始化**问题。

## 知识背景

### 地址划分与查找

以"2 路组相联、16KB、16B 行"为例，32 位地址切成三段：

```text
| Tag       | Index    | Offset(4b) |
  比较用       选组用      行内字节选择
```

查找：Index 选组 → 该组各路比较 Tag **同时比较有效位 V** → 命中选出行，Offset 取数据；全不命中进入未命中流程。

### 未命中状态机

未命中是 Cache 控制的核心，一个读未命中的典型序列：

```text
按 LRU 选牺牲路 → [若牺牲行脏：先写回 AXI] → AXI 读入整行 → 填入、置 V → 应答 CPU
```

- **脏行写回**：牺牲路 dirty 时，先把旧数据写回内存才有位置放新行；
- **写策略**：课程通常要求**写直达+写分配**或**写回**（以讲义规定为准），两者对脏位、总线流量的影响截然不同；
- AXI 侧一次突发（burst）读整行，把实验 15 的通道时序用熟。

### 硬件初始化

FPGA 上电时 BRAM 内容随机，**V 位不可信**——不加处理的 Cache 可能"命中"一堆垃圾数据。解决法：设初值寄存器/初始化状态机，上电或复位后先把所有行的 V 清零，再允许访问。

## 任务要求

1. 实现规定规格的 Cache 模块（组数/路数/行大小按课程要求），CPU 侧类 SRAM、总线侧 AXI；
2. 实现未命中状态机：读分配、脏写回、AXI 突发；
3. 实现硬件初始化逻辑；
4. 独立仿真：命中率统计、命中/未命中时序波形、脏写回场景、随机总线延迟下的回归。

## 验收标准

- [ ] 命中时当拍应答、未命中正确走状态机取数；
- [ ] 脏行替换时旧数据正确写回（内存内容最终一致）；
- [ ] 复位后无需软件干预即可正确工作；
- [ ] 提交源码与实验报告。
