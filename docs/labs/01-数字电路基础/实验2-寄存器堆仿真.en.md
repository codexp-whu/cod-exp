# Lab 2: Register File Simulation

!!! info "Reference in the Book"

    [*CPU Design in Practice: LoongArch Edition*, 3.1.1 Practical Task 2: Register File Simulation](https://bookdown.org/loongson/_book3/chapter-digital-logic.html#subsec-exp2)

## Objectives

- Understand the role the register file plays in a CPU: the place where operands are held.
- Learn how to verify read/write timing by simulation, and how to read a waveform to confirm behavior.

## Tasks

The lab environment is in the `dc_env/exp2/` directory, with the following structure:
```
|--regfile.v             Register file source file.
|--rf_tb.v               Register file simulation file.
```

Simulate a register file design functionally, and learn how it behaves by examining the simulation waveform.

The register file source provided in the environment has a "two-read, one-write" structure: two read ports (with no enable control, so they are permanently enabled) and one write port.

### Interface Signals

| Signal | Direction | Width | Description |
| ---- | ---- | ---- | ---- |
| `clk` | Input | 1 | Clock |
| `we` | Input | 1 | Register file write enable |
| `waddr` | Input | 5 | Register file write address |
| `wdata` | Input | 32 | Register file write data |
| `raddr1` | Input | 5 | Register file read address 1 |
| `rdata1` | Output | 32 | Register file read data 1 |
| `raddr2` | Input | 5 | Register file read address 2 |
| `rdata2` | Output | 32 | Register file read data 2 |


## Steps

1. Create a new project in Vivado.
2. Click "Add Sources", choose design sources, and add regfile.v.
3. Click "Add Sources", choose simulation sources, and add rf_tb.v.
4. Run the simulation, and observe the register file's read and write behavior in the waveform viewer.
