# 实验2：寄存器堆仿真

!!! info "原书参考"

    [《CPU设计实战：LoongArch版》3.1.1 实践任务2：寄存器堆仿真](https://bookdown.org/loongson/_book3/chapter-digital-logic.html#subsec-exp2)

## 实验目标

- 理解寄存器堆（Register File）在 CPU 中的角色：运算操作数的暂存场所。
- 掌握读写时序的仿真验证方法，学会观察波形确认行为。

## 实验内容

具体的实验环境位于 dc_env/exp2/ 目录下，其目录结构如下：
```
|--regfile.v             寄存器堆源码文件。
|--rf_tb.v               寄存器堆仿真文件。
```

对一个寄存器堆设计进行功能仿真，通过观察其仿真波形了解行为特征。

实验环境中提供的寄存器堆源码为“两读一写”的结构，也就是有两个读端口（读端口没有使能位控制，表示永远使能）和一个写端口。

### 接口信号

| 信号 | 方向 | 位宽 | 说明 |
| ---- | ---- | ---- | ---- |
| `clk` | 输入 | 1 | 时钟 |
| `we` | 输入 | 1 | 写使能寄存器堆写使能 |
| `waddr` | 输入 | 5 | 寄存器堆写地址 |
| `wdata` | 输入 | 32 | 寄存器堆写数据 |
| `raddr1` | 输入 | 5 | 寄存器堆读地址1 |
| `rdata1` | 输出 | 32 | 寄存器堆读返回数据1 |
| `raddr2` | 输入 | 5 | 寄存器堆读地址2 |
| `rdata2` | 输出 | 32 | 寄存器堆读返回数据2 |


## 实验步骤

1. 使用Vivado新建一个工程。
2. 点击“Add Sources”，选择添加设计源码（design sources），加入regfile.v。
3. 点击“Add Sources”，选择添加仿真源码（simulation sources），加入rf_tb.v。
4. 对工程进行仿真测试，结合波形观察寄存器堆的读写行为。
