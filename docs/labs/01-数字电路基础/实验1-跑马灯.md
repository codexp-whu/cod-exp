## 实验目标
掌握Vivado创建工程、仿真、上板流程。

## 实验内容
具体的实验环境位于 `dc_env/exp1/` 目录下，其目录结构如下：
```
|--scroller.v    跑马灯的设计源文件
|--scroller.xdc  跑马灯的设计约束文件
|--testbench.v   跑马灯的仿真源文件
```

用提供的三个文件：scroller.v（设计文件）、scroller.xdc（约束文件）和testbench.v（测试文件），构建Vivado工程，完成跑马灯设计的仿真和上板。

## 实验步骤
**无需修改任何代码!!!**

1. 使用Vivado新建一个工程。
2. 点击“Add Sources”，选择添加设计源码（scroller.v）。
3. 点击“Add Sources”，选择添加仿真源码（simulation sources），加入testbench.v。
4. 对工程进行仿真测试，结合波形观察LED信号。
5. 上板。

## 验收标准
- [ ] 上板有跑马灯效果即可。
