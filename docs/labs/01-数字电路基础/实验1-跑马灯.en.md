## Objectives
Get comfortable with the Vivado workflow: creating a project, running a simulation, and programming the board.

## Tasks
The lab environment is in the `dc_env/exp1/` directory, with the following structure:
```
|--scroller.v    Source file for the running light design
|--scroller.xdc  Constraints file for the running light design
|--testbench.v   Simulation file for the running light design
```

Using the three files provided — scroller.v (the design), scroller.xdc (the constraints) and testbench.v (the testbench) — build a Vivado project, then simulate and program the running light design.

## Steps
**You do not need to modify any code!!!**

1. Create a new project in Vivado.
2. Click "Add Sources" and add the design source (scroller.v).
3. Click "Add Sources", choose simulation sources, and add testbench.v.
4. Run the simulation, and observe the LED signal in the waveform viewer.
5. Program the board.

## Acceptance Criteria
- [ ] The running light effect is visible on the board.
