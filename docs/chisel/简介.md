# 从 Verilog 到 Chisel

这份讲义内容围绕五级流水线 CPU 展开，只介绍实现过程中会用到的 Scala 和 Chisel。

建议按下面的顺序学习：

1. 先把环境跑通，确认能生成 Verilog。
2. 学习基础语法，能够编写小模块。
3. 学习模块测试和时序测试，并在开发过程中持续验证。
4. 再进入流水线寄存器、转发、暂停和冲刷。

后面的例子会尽量和 Verilog 对照。

## Chisel 是什么

Chisel 的全称是 **Constructing Hardware in a Scala Embedded Language** 。它是一个建立在 Scala 之上的硬件构建库，不是一门与 Scala 无关的新语言。

你写下的 Chisel 代码会先作为 Scala 程序运行，构造出电路，再由工具链生成 **Verilog 或 SystemVerilog** 。生成的结果仍然可以交给 Verilator 做 RTL 仿真，也可以交给 Vivado 仿真、综合并实现到 FPGA。

```text
Scala / Chisel 源码
        ↓
运行 Scala，构造电路
        ↓
生成 Verilog / SystemVerilog
        ↓
仿真、综合、上板
```

这里需要区分两层含义：

- `for`、`if`、类和函数等 Scala 语法，通常在**生成电路时**执行。
- `Mux`、`when`、`Reg`、`:=` 等 Chisel 写法，描述的是**生成出来的硬件**。

如果混淆这两个阶段，代码即使能编译，也可能生成与预期不同的电路。后面的语法章节会继续说明这一点。

## 为什么要使用Chisel

单周期 CPU 的规模不大，手工连线通常还能应付。到了流水线 CPU，问题会明显放大：

- 每级流水线寄存器都要携带一批数据和控制信号。
- 新增一个控制信号，往往要同时修改多个模块和级间寄存器。
- 转发、暂停和冲刷会让顶层连接迅速变复杂。
- 位宽、级数、队列深度等参数容易散落在代码各处。

!!! tip 
    Chisel 不能替你解决流水线冒险，也不能保证架构设计正确。它主要用于 **生成重复结构、组织相关信号，并在生成阶段检查一部分连接和类型问题** 。


## 先看几个对照

下面的代码现在不要求看懂，直观感受一下Chisel的简洁。

### 多路选择器

Verilog 中常用 `case`：

```verilog
always @(*) begin
    case (sel)
        2'd0: out = a;
        2'd1: out = b;
        2'd2: out = c;
        default: out = d;
    endcase
end
```

Chisel 可以把选择关系写成一张表：

```scala
val out = MuxLookup(sel, d)(Seq(
  0.U -> a,
  1.U -> b,
  2.U -> c
))
```

这两段代码都会生成组合选择逻辑。`MuxLookup` 并不是软件查表，也不会在运行时逐项搜索。

### 寄存器堆

Chisel 的 `Vec` 可以按硬件下标访问，很适合描述小型寄存器阵列：

```scala
val regs = RegInit(VecInit(Seq.fill(32)(0.U(32.W))))

val rdata1 = Mux(rs1 === 0.U, 0.U, regs(rs1))
val rdata2 = Mux(rs2 === 0.U, 0.U, regs(rs2))
```

写端口仍然是时序逻辑：

```scala
when(wen && rd =/= 0.U) {
  regs(rd) := wdata
}
```

这里的 `when` 不是“时序语句”。之所以生成寄存器写入，是因为赋值目标 `regs(rd)` 来自 `Reg`。同一个 `when` 也可以用于控制 `Wire`，那时生成的是组合逻辑。

### 成组传递信号

流水线级间常常需要一起传递 PC、指令和有效位。可以先把它们放进一个 `Bundle`：

```scala
class IfId extends Bundle {
  val valid = Bool()
  val pc    = UInt(32.W)
  val inst  = UInt(32.W)
}
```

然后用一个寄存器保存整组信号：

```scala
val ifId = RegInit(0.U.asTypeOf(new IfId))
val ifIdNext = WireDefault(ifId)

ifId := ifIdNext
```

增加字段时，在 Bundle 定义中加入该字段。产生这组信号的逻辑仍需补充相应连接，编译器会检查未驱动的字段。

## 仍需自行处理的设计问题

初学时同学们容易把“代码短”误解为“硬件简单”，但两者不是一回事，Chisel简单的代码仍然会生成同样的硬件结构。

- 一行乘法仍然会生成乘法器。
- 一个按硬件信号索引的 `Vec` 仍然可能生成很大的多路选择器。
- 很长的组合表达式仍然可能成为关键路径。
- `for` 循环会展开硬件，不会让同一份硬件自动重复使用多个周期。

!!! tip
    写 Chisel 时仍需关注位宽、时序、并行性和资源。Chisel 主要 **改变代码的组织和生成方式，不改变这些硬件约束** 。

!!! warning
    一定要时刻记住 **不同的Chisel写法会生成不同的硬件结构!!!**
