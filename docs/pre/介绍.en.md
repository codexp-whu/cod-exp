To do good work, one must first sharpen one's tools. Before we formally begin the labs, some preparation is needed.

The lab environment for this course has three parts: **Vivado**, a **WSL2/Linux environment**, and the **LoongArch32 cross-compilation toolchain**.

### Vivado

Use a Vivado version **2019.2 or later**; **2023.2** is recommended, as it noticeably speeds up simulation, synthesis, and implementation.

For a detailed Vivado installation guide, see: [Installing Vivado](https://bookdown.org/loongson/_book3/appendix-vivado-install.html)

!!! note "Tips for using Vivado"
    - Windows builds of Vivado compile with 2 threads by default. Type the following command in the Tcl Console to enable 8-thread compilation and speed things up: `set_param  general.maxThreads 8`
    - Synthesis and implementation are faster under Linux. If you have a physical Linux machine, consider installing the Linux version of Vivado.
    - Running Vivado inside a virtual machine is not recommended.
    - Do not use non-ASCII (Chinese) characters in the project path, and do not nest the project too deeply — creating the project directly under the root of a drive is recommended.
    - Do not use non-ASCII (Chinese) characters in your computer user name.

For the basic Vivado workflow (creating a project, running simulations, and programming the board), see the appendices of the book: [Getting Started with Vivado](https://bookdown.org/loongson/_book3/appendix-vivado-startup.html) and [Advanced Vivado Usage](https://bookdown.org/loongson/_book3/appendix-vivado-advanced-usage.html).

### WSL2 / Linux Environment

We recommend using WSL2 with Ubuntu on Windows. The later labs require a Linux environment in which to compile the test programs.

Please look up a tutorial for installing WSL2 with Ubuntu on your own.

### LoongArch32 Cross-Compilation Toolchain

Compiling the `func` programs yourself requires the LoongArch32R GCC cross-compiler. You can download the toolchain package from [LoongArch32 Reduced Cross Toolchain](https://gitee.com/loongson-edu/la32r-toolchains/releases).

When downloading the package, choose the version matching your machine (X86 or LoongArch); the X86 case is used as an example below. **Download [loongson-gnu-toolchain-8.3-x86_64-loongarch32r-linux-gnusf-v2.0.tar.xz](https://gitee.com/loongson-edu/la32r-toolchains/releases/download/v0.0.3/loongson-gnu-toolchain-8.3-x86_64-loongarch32r-linux-gnusf-v2.0.tar.xz) ** into the Linux operating system's own file system. Note in particular that the X86 version of the LoongArch32R GCC cross-compiler currently supports only 64-bit systems (that is, systems where the `uname -a` command reports the architecture as x86_64). Then:

**In the Linux environment:**

(1) Open a terminal, change into the directory containing the archive, and extract it:
```
sudo tar Jxvf loongson-gnu-toolchain-8.3-x86_64-loongarch32r-linux-gnusf-v2.0.tar.xz -C /opt/
```

(2) Then run:
```
echo 'export PATH=/opt/loongson-gnu-toolchain-8.3-x86_64-loongarch32r-linux-gnusf-v2.0/bin/:$PATH' >> ~/.bashrc && source ~/.bashrc && echo $PATH
```
(3) Open a new terminal and check the version of the la32r GCC cross-compiler:
```
 loongarch32r-linux-gnusf-gcc -v
```
If the GCC version is printed correctly, the setup is complete.
