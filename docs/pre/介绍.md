“工欲善其事，必先利其器”，在正式开始实验之前，我们需要进行一些准备工作。

本课程的实验环境由三部分组成：**Vivado**、**WSL2/Linux 环境**以及 **LoongArch32 交叉编译工具链**。

### Vivado

在实验中应使用版本**高于或等于2019.2**的Vivado，推荐使用**2023.2**版本Vivado，能够有效加快仿真和综合实现速度。

详细地Vivado安装教程请参考：[Vivado的安装](https://bookdown.org/loongson/_book3/appendix-vivado-install.html)

!!! note "使用Vivado的小贴士"
    - Windows版本Vivado默认2线程编译，可在Tcl Console中输入如下命令：`set_param  general.maxThreads 8` 开启八线程编译加速
    - Linux下Vivado的综合实现速度更快，若有Linux物理机可选择安装Linux版本Vivado
    - 不建议在虚拟机中使用Vivado
    - 工程所在位置的路径不要出现中文，工程所在路径也不应过深，建议直接在磁盘根目录下创建项目
    - 计算机用户名不要使用中文

Vivado 的基本操作（建工程、仿真、上板）可参考原书附录：[Vivado使用入门](https://bookdown.org/loongson/_book3/appendix-vivado-startup.html)、[Vivado使用进阶](https://bookdown.org/loongson/_book3/appendix-vivado-advanced-usage.html)。

### WSL2 / Linux 环境

推荐在Windows使用WSL2+Ubuntu，后续实验环境需要在Linux环境下编译测试程序。

安装WSL2+Ubuntu教程请自行查阅。

### LoongArch32 交叉编译工具链
自行编译func程序需要使用LoongArch32R的GCC交叉编译工具。该工具链的安装可以从 [LoongArch32精简版交叉工具链](https://gitee.com/loongson-edu/la32r-toolchains/releases) 下安装包。

下载安装包时请根据所用机器是X86还是LoongArch选择对应的版本,以下以X86为例。**下载压缩包 [loongson-gnu-toolchain-8.3-x86_64-loongarch32r-linux-gnusf-v2.0.tar.xz](https://gitee.com/loongson-edu/la32r-toolchains/releases/download/v0.0.3/loongson-gnu-toolchain-8.3-x86_64-loongarch32r-linux-gnusf-v2.0.tar.xz) **至Linux操作系统自身的文件系统中。需要特别提醒的是，目前X86版本LoongArch32R的GCC交叉编译工具只支持64位系统（在系统下运行`uname -a`命令显示架构为x86_64的）。接下来：

**在Linux环境下：**

（1）打开一个terminal，进入压缩包所在目录，进行解压：
```
sudo tar Jxvf loongson-gnu-toolchain-8.3-x86_64-loongarch32r-linux-gnusf-v2.0.tar.xz -C /opt/
```

（2）随后执行：
```
echo 'export PATH=/opt/loongson-gnu-toolchain-8.3-x86_64-loongarch32r-linux-gnusf-v2.0/bin/:$PATH' >> ~/.bashrc && source ~/.bashrc && echo $PATH
```
（3）重新打开一个terminal，查看la32r的gcc交叉编译链版本：
```
 loongarch32r-linux-gnusf-gcc -v
```
若正确输出gcc版本即配置成功。
