    环境搭建¶

    这一节在 Linux 环境中使用课程模板自带的 Mill 编译一个 Chisel 模块，并生成 SystemVerilog。

    开发环境¶

    强烈建议使用 WSL2或者Linux 虚拟机/物理机 完成实验，下面的教程以 WSL2+Ubuntu 为例进行讲解。

    硬件开发环境选择

    建议Chisel代码编写和Vivado综合实现均在 Linux 环境下完成。

    安装 WSL2 / Linux虚拟机 / Linux物理机¶

    请自行查阅相关安装教程。

    安装基础工具¶

    下面的命令都在 Ubuntu/Linux 终端中执行。先更新软件索引：

    sudo apt update

    安装 JDK、Git 和本地编译工具：

    sudo apt install -y openjdk-17-jdk git curl
sudo apt install -y build-essential

    再安装本课程会用到的 RTL 仿真与波形工具：

    sudo apt install -y verilator gtkwave

    这些工具各自负责的事情并不复杂：

    工具 在课程中的作用
    JDK 17 运行 Scala 和 Chisel
    Git 管理代码版本
    g++、make 编译 Verilator 生成的 C++ 仿真模型
    Verilator 仿真生成的 SystemVerilog
    GTKWave 打开 VCD 波形文件

    用版本命令检查安装结果：

    java -version
git --version
g++ --version
verilator --version

    这些命令都能输出版本信息时，系统工具已经安装完成。GTKWave 在带 WSLg 的 Windows 11 上通常可以直接打开；若虚拟机中打不开图形界面，先确认虚拟机桌面和图形支持是否正常。

    最小的Chisel项目¶

    我们在实验中使用 OSCPU 提供的 Chisel模板，已经包含了测试和生成脚本，开箱即用。

    1. 克隆项目 
      git clone https://github.com/OSCPU/chisel-playground.git
    2. 安装Mill 
      cd chisel-playground

 curl -L https://repo1.maven.org/maven2/com/lihaoyi/mill-dist/1.1.8/mill-dist-1.1.8-mill.sh -o mill
 chmod +x mill
 ./mill version
      运行后会自动下载依赖文件，当看到输出版本号即为成功配置了环境。
    3. 测试和生成verilog 
      // 测试
make test

// 生成verilog
make verilog
      生成的verilog文件会在 build 文件夹下。

    项目基本结构¶

    chisel-playground/
├── .github/workflows/     # GitHub Actions CI 配置
├── src/                   # 源代码目录
│   ├── GCD.scala          # GCD 模块实现
│   ├── DecoupledGCD.scala # 带 Decoupled 接口的 GCD 模块
│   └── Elaborate.scala    # 顶层封装，用于生成 Verilog
├── test/
│   └── src/
│       └── GCDSpec.scala  # GCD 模块的测试代码
├── .gitignore             # Git 忽略文件配置
├── .scalafmt.conf         # Scala 代码格式化配置
├── Makefile               # 封装 Mill 常用命令
├── build.mill             # Mill 构建定义文件
└── README.md              # 项目说明文档

    Tip

    如果需要替换 GCD 模块，打开 src/Elaborate.scala，这是生成 Verilog 的入口。你需要将里面的 new GCD() 替换为 new MyALU()（或你的模块名） ！ 新增的Chisel文件放在 src 文件夹下即可。

    vscode开发环境¶

    建议安装Scala(Metals),Scala Syntax (official),Chisel syntax插件实现代码高亮和代码提示补全。
